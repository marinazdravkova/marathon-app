# Stip Marathon 2026 - Web Application

This is a modern, responsive web application for the Stip Marathon, built using React. The project features a dynamic countdown timer, a registration form, and an interactive user interface. 

The idea lays on developing one fully functional, modern Web Application for Marathons. All in one place that is need when organizing one marathon, online informations, details and dynamic access for registering.

🚀 Features
Dynamic Countdown: A live timer counting down to the start of the race.

Responsive Design: Fully optimized for mobile devices with a modern hamburger navigation menu.

Interactive Components: Navbar with "smooth scroll" effects and a customized Google Map in the footer.

Form Validation: A registration system for runners with real-time data validation.

🛠 Tech Stack
React.js (Vite)

CSS3 (Flexbox, Grid, Animations)

JavaScript (ES6+)

Google Maps API (Embed)
